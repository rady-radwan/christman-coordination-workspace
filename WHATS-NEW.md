# What's new

Shown in the app's "new version" message. Add a section for each version (newest first);
lines starting with "- " are the points.

## 0.6.0
- Item page: the photo and the description sit side by side; set the photo size and the description text size in Settings
- Drag the edges between panels (sidebar, item list, item page, facts) to make them wider or narrower
- Schedule: zoom in and out, or fit the whole schedule to the screen
- Lighter priority colors on item cards (adjustable in Settings)

## 0.5.0
- Announcements: important news from the Christman VDC team, with a notification for everyone
- BEP: the Project BEP File at the top, sections with tables, checklists, note boxes and pictures, Word import, "Show more" for long sections, and easy arranging
- Clash Reports: summary sheets look like Excel, with the numbers calculated
- Notifications: older ones are dimmed and can be deleted
- New-version alert with a download button

## 0.4.0
- Next-meeting agenda and "before the meeting" list
- BIM Execution Plan section and clash reports viewer
